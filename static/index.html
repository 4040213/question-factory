🔊 语音反馈素材 v2 拖入自动识别
① 下载组课文档的语音压缩包 → 解压 → 把 mp3/wav 文件拖到下方区域（或点击选择文件）；

命名规范：正反馈 _r · 负反馈 w_步_次(如 w_1_2) · 题干音频 _tg(或 _s/朗读/配音) · 自动提示音频 _tips(提示1) / _tips2 或 _tips_2(提示2) / _tips3 或 _tips_3(提示3)。未识别的文件会标黄。
