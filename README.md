# 试题批量生成工具

从 Excel 表格批量导入选择题/填空题到「莫顿教学系统」，支持飞书文档一键导入，自动完成题目创建、画布排版、通用反馈、条件反馈，以及**自动提示（AI 辅助提示）**配置。素材通过「文件名前缀 = 题名（公司编码）」自动匹配；题名填友好名时也可通过 `static/name-map.json` 别名映射自动匹配（详见[命名别名映射](#命名别名映射友好名--公司编码)），无需改 Excel、无需映射列。

## 这是什么？

莫顿教学系统（tms-mx.xueqiulearning.com）里手动创建题目费时费力。本工具支持三种导入方式：

1. **Excel 导入** — 在 Excel 模板里填好题目，上传即解析
2. **飞书导入** 🪶 — 粘贴飞书文档链接，自动拉取表格数据生成 Excel
3. **手动导入** — 网页填写题目信息后批量生成

**支持题型**：选择题（2~8 选项）、填空题（单空/双空，内容型/选项型）

**项目规模**：Python + HTML/CSS/JS + Node.js，86 个自动化测试。

**核心约定（最新）**：题名（飞书「位置」列 / Excel「名称」列）**推荐直接填公司编码**（如 `26sug2w1D1P1-1`）；素材文件名前缀 = 同一编码。解析器按「文件名前缀 == 题名」自动匹配，**无需任何手动映射列**，全程零手填。若题名填的是**友好名**（如 `轻互动1-1`），只要 `static/name-map.json` 里有「友好名 ⇄ 公司编码」别名（见[命名别名映射](#命名别名映射友好名--公司编码)），编码命名的素材同样能自动匹配，无需改 Excel。

## 飞书文档导入 🪶

> 粘贴飞书文档链接 → 点「转换」→ 题目自动出现在网页列表里，跟手动上传 Excel 完全一样。

### 原理：数据怎么从飞书到莫顿？

```
飞书百科文档
  ↓ ① 飞书 Open API (Blocks API)
结构化块数据（table / text / image block）
  ↓ ② python 解析
question dicts（内存）
  ↓ ③ openpyxl 写入
本地 Excel 文件（D:\A工作\题目生成工作流\选择题_生成结果.xlsx / 填空题_生成结果.xlsx）
  ↓ ④ 前端自动 fetch → handleFileUpload()
前端题目列表（跟手动上传 Excel 完全一致）
  ↓ ⑤ 用户点「批量生成」
莫顿教学系统 API（逐题创建 + 画布排版 + 反馈配置 + 自动提示）
```

### 文件储存

| 文件 | 路径 | 说明 |
|---|---|---|
| 选择题模板 | `D:\A工作\题目生成工作流\选择题(模板) - 副本.xlsx` | 31 列模板，只读 |
| 填空题模板 | `D:\A工作\题目生成工作流\填空题（模板）.xlsx` | 37 列模板，只读 |
| **选择题生成结果** | `D:\A工作\题目生成工作流\选择题_生成结果.xlsx` | 每次转换覆盖 |
| **填空题生成结果** | `D:\A工作\题目生成工作流\填空题_生成结果.xlsx` | 每次转换覆盖 |
| 飞书图片 | `D:\A工作\题目生成工作流\飞书图片\` | 按 image_token 命名 |

> 生成的 Excel 和模板同目录，方便你手动核对或修改后重新上传。

### 解析步骤详解

**① Blocks API 结构化解析**（非文本切割）

旧方案用 `raw_content` 文本 + 空行分割 → 题目含内部空行时（如"拖拽效果"前空行、"image.png"后空行）8 列对齐崩溃。v2 改用 Blocks API：

- 递归遍历文档 block 树（block_type: 1=页面 2=文本 4=分隔线 27=图片 31=表格 32=单元格）
- 找出所有 `block_type=31` 表格 → 每 8 个单元格一行 → 第一行是表头，后面是数据
- 递归读取单元格内容：文本块（block_type=2）+ 图片块（block_type=27）+ 行内图片（inline_image）
- 子 block 间自动加 `\n`，保留文档段落结构

**② 题目分类 & 属性提取**

- **选项识别**：统一扫描所有 `[A-H][.、．]` 标记（支持同行多选项、跨行选项、中文全角标点）
- **选择题**：≥2 个选项 → 题干 = 第一个选项之前的文本
- **填空题**：无选项 → 统计 `(   )` 或 `______` 数量 → 单空 / 双空
- **答案处理**：自动去空格 → 支持 BD 多选、跨行答案（如 `蓝球\n白球`）
- **跳关条件**：「错一次过」→ min=1,max=1；「错三次过」→ min=1,max=3
- **名称（★ 最新约定）**：飞书「位置」列 = **公司编码**（如 `26sug2w1D1P1-1`）为推荐写法，该编码即题目身份、也是素材文件名前缀，解析器据此自动匹配素材，**无需任何"标准编码"列**。若填友好名（如 `轻互动1-1`），需在 `static/name-map.json` 配「友好名 ⇄ 公司编码」别名才能匹配编码命名的素材（见[命名别名映射](#命名别名映射友好名--公司编码)）。

**③ 负反馈 → 条件反馈映射**

飞书「负反馈」列含多级文本（负反馈一/二/三），对应每次答错的不同提示。写入 Excel 时：

| 飞书内容 | Excel 列 | 对应莫顿字段 |
|---|---|---|
| 负反馈一（第一段提示） | 21「答错通用反馈」 | wrongFeedback（通用，任何错次都显示） |
| 全部负反馈（清洗标签后合并） | 29「条件反馈文本」 | conditionFeedbacks[0].content |
| 跳关条件 | 27「最少错次」/ 28「最多错次」 | minWrong / maxWrong |

**④ 图片处理**

block_type=27 或 inline_image → 提取 `image_token` → 调用 `GET /drive/v1/medias/{token}/download` 下载到本地 `飞书图片/` 目录 → token 写入 Excel 第 19 列「题目图片」。

### 飞书文档格式要求

| 位置（=公司编码） | 知识点 | 题目 | 答案 | 正反馈 | 负反馈 | 跳关条件 | 场景设置 |
|---|---|---|---|---|---|---|---|
| 26sug2w1D1P1-1 | 概率 | 下列事件中...<br>A.xxx B.xxx C.xxx D.xxx | D | 太棒了 | 负反馈一：再想想<br>负反馈二：提示<br>负反馈三：解释 | 错一次过 | |

- 8 列顺序固定，每道题一个表格
- 「位置」列填写**公司编码**（如 `26sug2w1D1P1-1`）为推荐写法，该编码须和素材文件名前缀一致；若填友好名（如 `轻互动1-1`），需在 `static/name-map.json` 配别名才能匹配编码命名素材（见[命名别名映射](#命名别名映射友好名--公司编码)）
- 题目列支持 A.xxx / B.xxx 等多行选项或同行选项
- 填空题为 `(    )` 或 `______` 格式
- 负反馈支持多级（负反馈一/二/三），自动拆分到通用答错 + 条件反馈
- 支持嵌入图片（block 图片或行内图片）

## 素材命名规范 ★

**核心规则**：素材文件名 = `{题名}_{功能后缀}`。解析器按前缀匹配题名，分隔符 `-` 与 `_` 通用（如 `26sug2w1D1P1-1_A` 与 `26sug2w1D1P1_1_A` 等效；`轻互动1-1-bg.jpg` 短横与 `轻互动1-2_bg.jpg` 下划线都支持）。题名通常是公司编码（如 `26sug2w1D1P1-1`），填友好名时经 `name-map.json` 别名翻成对应编码再匹配（见[命名别名映射](#命名别名映射友好名--公司编码)）。

### 图片命名

| 类型 | 命名 | 示例 |
|---|---|---|
| 背景图 | `{题名}_bg` | `26sug2w1D1P1-1_bg` |
| 选项图 A~H | `{题名}_a` ~ `{题名}_h` | `26sug2w1D1P1-1_a` |
| 题目图 | `{题名}_stem` | `26sug2w1D1P1-1_stem` |
| 自动提示图 1 | `{题名}_bulb` 或 `{题名}_小灯泡` | `26sug2w1D1P1-1_bulb` |
| 自动提示图 2 | `{题名}_bulb2` 或 `{题名}_小灯泡2` | `26sug2w1D1P1-1_bulb2` |
| 自动提示图 3 | `{题名}_bulb3` 或 `{题名}_小灯泡3` | `26sug2w1D1P1-1_bulb3` |

### 音频命名

| 类型 | 命名 | 示例 |
|---|---|---|
| 题干音频（朗读/配音） | `{题名}_tg`（兼容 `_s` / `_stem` / 关键词「题干\|配音\|朗读\|narration\|题目音」） | `26sug2w1D1P1-1_tg` |
| 正反馈 | `{题名}_r` | `26sug2w1D1P1-1_r` |
| 负反馈 | `{题名}_w_X_Y`（X=步序 1~3，Y=该步第几次出现） | `26sug2w1D1P1-1_w_1_2`（步1第2次） |
| 自动提示音频 1 | `{题名}_tips` 或 `{题名}_tips_1` | `26sug2w1D1P1-1_tips` |
| 自动提示音频 2 | `{题名}_tips2` 或 `{题名}_tips_2` | `26sug2w1D1P1-1_tips2` |
| 自动提示音频 3 | `{题名}_tips3` 或 `{题名}_tips_3` | `26sug2w1D1P1-1_tips3` |

**匹配关键点**：
- 图片走 `parseMortonName`（按 `_bg`/`_a`/`_stem`/`_bulb` 等后缀分配角色）
- 自动提示音频走 `parseAutoHintAudioName`（按 `_tips` 后缀 + 编号 → 第几个提示）
- 反馈音频走 `classifyVoiceFile`（按 `_tg`/`_r`/`_w_X_Y` 分配）
- 图片与音频编号独立配对：第 N 个提示图（`_bulbN`/`_小灯泡N`）对应第 N 个提示音频（`_tipsN`）

## 命名别名映射（友好名 ↔ 公司编码）★

当 Excel/飞书文档的题名填的是**友好名**（如 `轻互动1-1`），而莫顿素材库里的文件按**公司编码**命名（如 `26sug6w18d0p1-2-option-D`）时，两串字符之间无算法关系、无法直接相等匹配。本工具提供一份**纯数据**的别名映射文件 `static/name-map.json`，让公司编码天然成为该题的别名，自动识别匹配——**无需改 Excel、无前端界面、无 Excel 映射列**。

### 工作原理

```
素材 26sug6w18d0p1-2-option-D
  → parseMortonName 抠出前缀 26sug6w18d0p1-2
  → findQuestionByNameWithAlias 先按原名查题名：
      ① 题名=26sug6w18d0p1-2 直接命中 → 绑定
      ② 未命中 → 查 NAME_MAP：26sug6w18d0p1-2 ⇄ 轻互动1-1
         → 题名=轻互动1-1 命中 → 绑定 ✅
```

映射**双向自动展开**：写 `轻互动1-1=26sug6w18d0p1-2` 一条，两个方向都能查（编码作别名、友好名也作别名）。

### 配置文件：static/name-map.json

```json
{
  "轻互动1-1": "26sug6w18d0p1-2",
  "关卡1-1": "26sug6w18d0p1-3"
}
```

- 页面初始化时自动 `fetch('name-map.json')` 加载，**刷新即生效**，纯数据、无界面
- 追加新映射：编辑文件加一行 `"友好名": "公司编码"` 即可，无需触碰前端代码
- **覆盖通道**：图片素材、自动提示图片、自动提示音频（`_tips`）均已走别名
- 语音反馈角色（`right` / `wrong1~3` / `stem`）按文件名角色分配、不按题名，无需映射
- 与「做法1（题名=公司编码）」完全兼容：题名直接是编码时走①直接命中，别名仅作兜底补充

> 说明：此前曾有一个「🔗 命名映射」前端文本框 / 文件导入界面，已按需求移除；当前仅保留无界面的数据文件驱动方式。

## 自动提示（AI 辅助提示）★

自动提示对应莫顿 `auxiliaryTips.autoTip` 字段，是题目答题过程中按条件弹出的图片+音频辅助提示。

### 结构

- 每题最多 **3 个自动提示**
- 每个提示包含：**图片 + 音频 + 最多 6 个变量**
- 每个变量 = **触发状态 + 持续时间（秒）**，两者都必填

### 变量填写格式

```
状态:秒
```

- **状态**（三选一，中文或英文枚举均可）：
  - `无操作` → `NO_ACTION`
  - `未提交` → `NOT_SUBMITTED`
  - `未通关` → `NOT_PASSED`
- **时间**：整数秒
- 中英文冒号 `:` / `：` 均可
- 示例：`未提交:5`、`未通关:10`、`NO_ACTION:3`

> 变量值（状态/时间）可后续从需求文档爬取，当前在 Excel / 网页面板中填写。

### Excel 列（每提示一组，追加在末尾）

| 提示 | 图片列 | 音频列 | 变量列 |
|---|---|---|---|
| 提示 1 | `自动提示1图片` | `自动提示1音频` | `自动提示1变量1` ~ `自动提示1变量6` |
| 提示 2 | `自动提示2图片` | `自动提示2音频` | `自动提示2变量1` ~ `自动提示2变量6` |
| 提示 3 | `自动提示3图片` | `自动提示3音频` | `自动提示3变量1` ~ `自动提示3变量6` |

> 列名别名丰富（如 `自动提示第1图片` / `自动提示1图` / `自动提示图片`），解析时按规范名归并。第 1 个提示额外兼容旧单提示文档的无序号别名（`自动提示图片` / `自动提示音频` / `自动提示变量N`）。

### 网页面板

右侧「✨ 自动提示」面板，逐提示配置：图片（拖拽/读回）+ 音频（拖拽/读回）+ 变量（状态下拉 + 时间秒）。输出结构：

```json
{
  "imageUrl": "...",
  "audioUrl": "...",
  "variables": [
    { "operation": "未提交", "timeSeconds": 5 },
    { "operation": "NOT_PASSED", "timeSeconds": 10 }
  ]
}
```

## 莫顿素材库读回 ★

适用场景：**素材已在莫顿素材库**（自己传过或他人上传），本地没有任何文件也能完整生成题目。

### 图片读回

1. 打开莫顿素材库，把图片上传到一个文件夹（背景/选项图/题目图/自动提示图按[命名规范](#素材命名规范-)命名）
2. 复制该文件夹 ID（URL 中 `parentId=xxxx` 那段）
3. 网页「🔗 莫顿素材库 URL 读回」框填入 ID → 点「读回 URL」
4. 工具按文件名前缀自动匹配，回填到对应题的背景图/选项图/题目图/自动提示图

### 语音读回（独立文件夹）

图片和语音在莫顿通常是**不同文件夹**，因此语音单独处理：

1. 把语音 mp3 上传到**单独的语音文件夹**（按[命名规范](#素材命名规范-)命名）
2. 网页「🔊 语音读回」框填入该文件夹 ID → 点「读回语音」
3. 系统自动按文件名匹配 CDN 地址 → 题干音频 / 正反馈 / 负反馈 / 自动提示音频全部就绪

### 匹配逻辑

```
莫顿素材名 → parseMortonName / parseAutoHintAudioName 抠出前缀(公司编码)
           → findQuestionByNameWithAlias：
               ① 题名 == 前缀 直接命中
               ② 未命中 → 查 name-map.json 别名(友好名⇄编码)翻成题名再查
           → 命中即绑定
```

- 无需本地文件、无需手动改名
- 题名填友好名时，只要在 `name-map.json` 配了别名，编码命名的素材同样自动绑定（见[命名别名映射](#命名别名映射友好名--公司编码)）
- 也可用**本地拖拽上传区**替代读回（拖图片/音频 → 上传 → 自动匹配）

## 环境切换（正式 / 测试）★

莫顿分正式环境与测试环境，工具支持**自助可视化切换**，无需改代码或碰文件。

- **页头开关**：「当前环境：正式环境 / 测试环境」分段按钮，点击即切
- **状态徽标**：正式=绿、测试=橙，并显示当前 API URL
- **切换后**：原 Cookie 可能属于另一环境，自动清空鉴权并要求重新粘贴对应环境 Cookie 验证
- **持久化**：选择写入 `.env` 的 `MORTON_API`，重启仍生效
- **后端接口**：`GET /api/morton/env`（读当前）、`POST /api/morton/env`（切换，传 `key=formal|test` 或完整 `url`）

`.env` 示例：

```ini
# 莫顿环境切换
#   测试环境：tms.testing.xueqiulearning.com
#   正式环境：tms-mx.xueqiulearning.com
MORTON_API=https://tms-mx.xueqiulearning.com
```

> 鉴权另需 `MORTON_COOKIE`（staffId=...tokenCrm=...）、`MORTON_TOKEN`（Bearer ...），见 `fetch_morton_question.py`。

## 功能说明

### 智能画布布局引擎

候选评分制：生成 5 种布局候选（TEXT_ONLY / TEXT_LEFT_IMAGE_RIGHT / IMAGE_TOP_TEXT_BELOW / STACK_WITH_SCALE / IMAGE_VERTICAL），按溢出度和宽度适应性评分，选取最优。

- **绿框区域**：x=182~1152（宽970），y=130~580（高450）
- **字号自适应**：≤15字→50px, ≤40字→45px, >40字→40px
- **逐字测量**：中文 0.85×字号, 英文 0.55×字号, 标点 0.40×字号
- **选项**：弹簧公式等分 + 高度分级(100~130px)
- **降级兜底**：溢出时文本→图片上下堆叠，图片循环缩小

### 通用反馈 & 条件反馈

答错/答对支持文字+图片+音频。条件反馈基于错误次数触发（如错1次→"再试试"，错2~3次→"提示"）。

### 自动提示（AI 辅助提示）

见[独立章节](#自动提示ai-辅助提示)。每题最多 3 提示，每提示图片+音频+最多6变量（状态+秒）。

### SSE 实时进度

批量生成时每道题完成后立即推送进度事件，前端逐条渲染。

### 浏览器缓存已禁用

`Cache-Control: no-cache, no-store, must-revalidate`，更新代码刷新即可。

## 常见问题

| 问题 | 解决 |
|---|---|
| Excel 解析失败 | 检查表头列数/顺序 |
| Token 过期 | 重新登录莫顿，复制新 Cookie |
| 飞书转换无结果 | 检查文档权限 + 表头列名"位置/知识点/题目/答案/正反馈/负反馈/跳关条件/场景设置" |
| 截图不可用 | `npm install` 并确认 Chrome 已安装 |
| 素材读回后没绑定到题目 | 检查文件名前缀是否等于该题「名称」(公司编码)；若题名填的是友好名，确认 `static/name-map.json` 已配对应别名（见[命名别名映射](#命名别名映射友好名--公司编码)）；核对分隔符 `-`/`_` 用法与[命名规范](#素材命名规范-) |
| 自动提示没生成 | 检查 Excel 是否有「自动提示N图片/音频/变量」列；素材是否按 `_bulb`/`_tips` + 编号命名 |
| 切换环境后 Cookie 失效 | 环境切换会清空鉴权，重新粘贴对应环境 Cookie 点验证 |
| 本地没有素材文件 | 用「莫顿素材库 URL 读回」，填图片/语音文件夹 ID 即可复用莫顿已有素材，无需本地文件 |
